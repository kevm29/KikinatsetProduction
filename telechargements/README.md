# Fichiers à télécharger

Dépose ici les jeux en `.html` (ou `.zip`) proposés dans l'onglet « On télécharge et on joue ».
Le nom du fichier doit correspondre au champ `fichier` du projet dans `projects.json`
(par exemple `telechargements/regalia.html`). Tant qu'un fichier n'est pas là, sa carte affiche « Bientôt disponible ».
